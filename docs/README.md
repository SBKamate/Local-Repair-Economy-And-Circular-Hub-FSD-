# FixNear – Project Engineering Documentation 📚

Welcome to the offline technical engineering documentation folder for **FixNear – Local Repair Economy and Circular Hub**.

This directory holds the complete architectural models, actor-use case matrices, structured data flow diagrams, entity-relationship schemas, and software requirements specifications (SRS) prepared for project evaluation, defense, and laboratory submissions.

## Project Overview

FixNear connects households with damaged items (furniture, electronics, appliances, plumbing, wiring) to neighborhood repair technicians, reducing waste and fostering sustainable local micro-economies.
